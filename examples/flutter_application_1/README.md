
In pubspec.yaml make the dependences look like this

dependencies:
  flutter:
    sdk: flutter
  speech_to_text: ^7.3.0
  device_apps: ^2.2.0
  installed_apps: ^1.3.1
  url_launcher: ^6.1.14
  # The following adds the Cupertino Icons font to your application.
  # Use with the CupertinoIcons class for iOS style icons.
  cupertino_icons: ^1.0.8
 
Then in your terminal run  flutter pub get
or run these commands

flutter pub get speech_to_text 
flutter pub get device_apps  
flutter pub get installed_apps  
flutter pub get url_launcher:
